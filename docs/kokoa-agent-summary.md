# kokoa-agentの実行件数

2026-09-28。下段Agent欄では、プロジェクト名が `kokoa-agent`（大文字小文字は区別しない）と一致するセッションだけ、Codex・Claudeをまとめて先頭の1行に表示する。

例: `agent 💪3 ✅5`。💪は実行中、✅は完了。確認待ち・失敗・停止・更新なしは、該当する場合だけ `確認1` / `失敗1` / `停止1` / `不明1` を添える。G2のフォント情報にある💪と✅を使い、左の状態アイコンも維持する。個々のセッション名や実行ログはこの行に出さない。

件数は既存モニターの表示対象セッション数であり、Nebiの仕事総数や一日の累計ではない。完了は従来どおり15分で対象外になる。3分無更新で不明になったセッションを実行中には数えない。対象が0件なら行自体を消す。他のプロジェクトは従来の個別表示を維持し、元の `/api/agents` データも変更しない。

集計と画面生成はPCのdashboardで行う。G2のPlugin更新、LLM呼出、ログ収集元の追加は不要。確認はdashboardの型チェックと `agent-summary.test.ts` / `agent-flow.test.ts`。
